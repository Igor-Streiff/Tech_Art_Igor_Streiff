## VoxelParty (submódulo)

`VoxelParty/` es un **submódulo Git** apuntando a [github.com/Igor-Streiff/VoxelParty](https://github.com/Igor-Streiff/VoxelParty). Clonar con submódulos:

```bash
git clone --recurse-submodules https://github.com/Igor-Streiff/Tech_Art_Igor_Streiff.git
```

Demo publicada: **https://igor-streiff.github.io/VoxelParty/**
